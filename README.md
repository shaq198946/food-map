# 🍲 美食红黑榜 (Food Map Engine)

> **万赞真实测 · 避坑不踩雷**  
> 精选河南（洛阳 & 郑州）83 家 100% 真实在线名店的双榜美食决策地图引擎。

---

## 🌟 核心特性

- **双榜客观并存**：红榜推荐（高赞打卡地标）与黑榜吐槽（避雷防坑硬核名单）双模一键切换；
- **100% 真实探店直达**：每一家店铺唯一对应抖音博主现场点单实测单视频播放链接，0 坏链；
- **原生极简交互**：
  - **移动端**：单卡 78vw 黄金居中吸附，左右露出实体卡片引导横滑；推荐菜文字胶囊防冒泡单行横滑；
  - **PC 宽屏端**：大视野多卡平铺展开，当前激活卡片放大 1.05 倍立体突出，带呼吸光晕；
- **智能到店导航**：内置高德、腾讯、百度三大地图多协议一键到店导航；
- **用户收藏与数据治理**：本地持久化收藏夹（⭐ 我的收藏专属金标筛选）与六大纠错反馈机制。
