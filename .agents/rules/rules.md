# 美食探店项目开发与文档同步规则 (Project Rules)

## 核心守则
1. **中文交流**：所有回复、思考过程、任务清单、注释与文档必须使用中文。
2. **每次开发后必须同步更新项目文档**：
   - 每次代码迭代、功能上线或 UI 调整后，必须将最新功能、架构变动与数据更新同步写入 [`DEVELOPMENT.md`](../../DEVELOPMENT.md) 与 [`PROCESS.md`](../../PROCESS.md)。
3. **真实视频与数据保障**：严禁套用虚假视频链接，红黑榜客观并存。
4. **多端适配规范**：移动端单卡居中两翼露出实体；PC 端宽屏多卡并排，选中卡片放大 1.05 并加粗高亮边框突出显示。
